第一部分 · 可行性评估 FEASIBILITY ASSESSMENT
A1

模型集遍历与逐模型求解 model-set enumeration

for model ∈ library: plan = solve(model, points, tolerance)

对模型库中每个模型分别求解轨迹，得到各自的可达性与误差指标。库里有几个模型就生成几份评估结果。

指标来源：偏差与饱和在 B2–B6 的求解管道中同步算得（同一函数 planMotion），A 部分负责**判定与归因**，不重复计算。
A2

末端偏差评估 end-effector deviation metric

e_i = ‖ p_rebuild(s_i) − p_target(s_i) ‖₂ E_max = max_i e_i

把平滑后的曲率序列经正运动学重建，与等距重采样得到的目标点逐点比对，取全程最大偏差作为该项指标。

A3

曲率约束饱和检测 curvature saturation check

saturated_i = |κ_i| > κ_limit κ_limit = mean(kappaLimitByDirection[0..7])

逐段检查曲率是否触及模型允许上限，超限段打饱和标记。饱和本身不判失败，作为“已到能力边界”的附加信息输出。

A4

容差接受判据 tolerance acceptance criterion

feasible = (unreachable = ∅) ∧ (E_max ≤ ε + δ) ε = 2 mm, δ = 0.05 mm

两条同时满足才算可行：无不可达采样点、最大偏差在容差内。δ 只为抵消浮点比较误差，不构成额外放宽。

A5

失败归因 failure attribution

E_max > 5ε → 超可达域（臂长 / 曲率不足） otherwise → 精度超差

把“不可行”细分成两类可执行的原因，直接决定操作员该改轨迹还是改模型。

判定门禁 · Feasibility Gate

可行性评估未通过的模型不进入轨迹规划输出，也不会被下发。可行模型才携带其规划结果进入第二部分。

第二部分 · 轨迹规划 TRAJECTORY PLANNING
B1

C¹ 连续样条插值 Catmull-Rom spline interpolation

P(t) = ½[ 2P₁ + (−P₀+P₂)t + (2P₀−5P₁+4P₂−P₃)t² + (−P₀+3P₁−3P₂+P₃)t³ ]

将离散示教点插值为 C¹ 连续曲线。该样条为**插值型**（曲线过控制点），切向量由相邻点差分自动给出，无需附加边界条件。

对比折线：折线在节点处切向不连续，逆运动学求解会在该处产生曲率尖峰与饱和误判。
B2

弧长参数化与等距重采样 arc-length parameterization & uniform resampling

s_{i+1} = s_i + Δs Δs = 2 mm trajectory length L = Σ Δs_i

以**弧长**为自然参数重新参数化曲线，再按恒定 Δs 采样，得到几何分布均匀的目标点列，同时给出路径总长 L。

为何不用参数 t 均匀采样：Catmull-Rom 的参数化不均匀，按 t 等分会使高曲率区采样过密、直段过疏，逆解密度失真。
B3

查表插值逆运动学 table-lookup inverse kinematics (IDW)

d_j = ‖ tip(sample_j) − p_i ‖, j = 1..N w_j = 1 / (d_j + 1)², w̃_j = w_j / Σw Δl_i = Σ_j w̃_j · Δl_j (6 维度, K = 10) 初值 ← 上一点解（warm start）

以末端位置为索引在离线求解表上做**反距离加权插值（IDW, K 近邻）**，输出六路驱动丝位移与对应的曲率场。采用逐点热启动以维持解支连续。

K 的取值依据：K=4 时近邻集合切换导致权重和不连续，Δl 阶跃 1.6 mm；K=10 将其分摊至约 10%，阶跃降至 0.4 mm。
B4

曲率场降采样 curvature-field downsampling (61 → 12)

slot k ∈ [0,11] → s_k = (k + 0.5)/12 · L 节点线性插值，端点对齐（endpoint-aligned）

表内曲率场为 61 节点矢量 (κx, κy, |κ|)，控制层需要 12 段。按段中点抽取节点并线性插值，完成降维。

端点对齐：等距抽样会使首末段仅覆盖半个节点间距，重建形状系统性偏短。
B5

曲率序列低通滤波 low-pass filtering of curvature series

κ[i] ← ( κ[i−1] + 2κ[i] + κ[i+1] ) / 4 ×2 passes 对 (κx, κy) 分量独立滤波

二项式核 [1,2,1]/4（等价两次 [1,1]/2 卷积）构成一阶低通，两遍叠加扩大等效窗口，抑制近邻切换引起的阶跃。

为何按分量而非 (|κ|, φ)：对方向角 φ 滤波会在 ±π 处发生绕回，重建时臂体朝反向弯曲；分量域无此奇异性。
B6

分段常曲率正运动学 piecewise-constant-curvature forward kinematics

κ ≠ 0: x = (1 − cos κs)/κ, y = sin κs / κ H ← H · T(κ, φ, ds) 6 substeps / segment p ← H · [x, y, 0, 1]ᵀ 12 × 6 = 72 积分点

按 PCC 假设在段内解析求解，再以 4×4 齐次变换矩阵逐段连乘至基座系；子步划分使段边界曲率突变在几何上连续过渡。

模型简化：真实 Cosserat 解中 κ(s) 连续变化，此处段内视为常数，是重建误差的主要来源。
B7

轨迹参数化与输出 trajectory parameterization

durationMs = round( L / v · 1000 ) v = 20 mm/s output: samples[{ kx[], ky[], x, y, z }], durationMs

以恒定末端速度把几何路径映射为时间序列，输出执行层直接使用的采样点与总时长。

注意：此处 v 是**规划名义速度**，与驱动器实际可达速度无关，两者不匹配时的表现见右下“已知失配”。

数据源 · TDCRMOD1

  • KTB1 tau(6) + Δl_mm(6)
  • PTB1 4 骨架点 × 3（svc，米）
  • KSB1 弧长网格 61 节点
  • KKB1 曲率矢量 61 × 3
  • META N=1031 / τ_max / κ_peak

关键参数

  • 重采样步长 Δs = 2 mm
  • 近邻数 K = 10
  • 权重 1/(d+1)²
  • 滤波核 [1,2,1]/4 × 2
  • 积分子步 6 / segment
  • 容差 ε = 2 mm
  • 名义末端速度 v = 20 mm/s

模型近似（精度边界）

  • 段内 κ 恒定（PCC），连续曲率被阶梯化
  • IK 仅以末端位置为索引，不含姿态约束
  • 滤波各向同性，真实尖转折被一并削弱

已知失配

  • 规划名义速度 20 mm/s，实测驱动可达 2 mm/s
  • 比值约 1:10，导致行程完成度仅 38%~82%
  • 需统一速度标定或改速度前馈下发

两部分的耦合方式

  • 代码中 A、B 共用求解管道（planMotion）
  • A 输出判定，B 输出轨迹，不重复计算
  • 门禁失败时轨迹不产出、不下发
